A review step for your coding agent

Human-in-the-loop markdown review for AI agents

Your agent writes a markdown draft — a plan, a spec, a PR summary. You review it in the browser with threaded comments. It reads them back over HTTP or MCP, replies, resolves, and pushes a revision.

$curl -fsSL https://mdreview.space/install.sh | sh

One command. It asks how you want to run it, local or hosted. On claude.ai instead? Add the connector.

How it works

A tight loop between your agent and you

1

Your agent drafts

Claude Code writes a markdown draft — a plan, spec, or summary — and hands it to mdreview instead of charging ahead.

2

You review in the browser

Read it, leave threaded comments, request changes, or approve. No account needed for local.

3

The agent revises

It reads your comments back over HTTP or MCP, replies, resolves threads, and pushes a new draft.

Repeat until you approve — the agent never ships past a review you haven't signed off on.

Coding was never the bottleneck. Thinking was.

Agents generate code instantly — but instant, unreviewed output falls over. mdreview puts a plan-and-review checkpoint back in the loop.

Get started

Add mdreview to your agent

Sign in with any email address. There is no invite list. Pick the route that matches your agent.

claude.ai custom connector

No token needed

Works in claude.ai on the web, Desktop and mobile. In claude.ai open Settings, then Connectors, then Add custom connector, and enter this URL.

https://app.mdreview.space/mcp

Claude opens the mdreview sign-in. Enter your email, follow the one-time link, and approve the connection on the consent page. You can revoke it later on your Account page.

Claude Code plugin

Run these two commands inside Claude Code. The plugin asks for a token, which you mint on the Account page after signing in at app.mdreview.space.

/plugin marketplace add ranawaqas-ai/mdreview-service /plugin install mdreview@mdreview

Installer

Needs python3 and the claude CLI. It asks whether to run locally or use the hosted instance, and prompts for a token if you choose hosted.

curl -fsSL https://mdreview.space/install.sh | sh

Two ways to run it

Your machine, or ours

Local

Open to everyone

Runs on your machine — no account, no Docker. Starts mdreview on localhost:8137 and wires Claude Code straight to it.

Hosted

Open to everyone

Use the managed instance at app.mdreview.space. Sign in with any email address; you get a one-time link, no password and no invite.
